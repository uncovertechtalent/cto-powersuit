# Example MOC (map of content)

A MOC is an index note a cluster earns once it has enough atoms to need one. One line per atom, saying why you'd open it:

- [[Example Atom - Consequence Budgeting]] — pricing consequences before purchase; the maturity frame.
- [[Reversibility Test]] — (unwritten) the cheap first check before any consequence math.

Rules of thumb: grow MOCs at ~7 atoms, never create them first, and keep the one-liners honest — they are what search snippets and future-you skim.
